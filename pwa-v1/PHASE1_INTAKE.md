# 第一阶段：图片识别与自动填充（2026-11-17）

已实现：入口 → 选择单张图片 → 本机预处理暗色截图/限制长边 → 中英文 OCR → 版式解析 → 自动填入待核对表单 → 人工确认加密保存。订单号忽略，不上传图片与识别原文。

覆盖字段：对阵、投注选择、明确标注的金额/返还、@赔率、玩法/局数/赛前滚球、投注时间、开赛时间原文、单注/串关、结算状态。已结算默认使用“其他结算”，不从图标颜色推断输赢。未知字段不能据模板补猜，未知结算时间允许保存，并从结算日统计排除；未归期亏损保守计入风险占用。

串关：保留结构化分项，可逐字段编辑/增删；本金仅在整单记一次，不把分项赔率乘积当作实际整单赔率。选择、分项和开赛原文进入加密状态、备份、审计与 CSV；不破坏旧记录。

验证：合成版式测试覆盖单注、串关、OCR日期空格、图标噪声、三位小数尾零、精度拒绝、最高可赢排除、多订单截断提示。用户提供的一张暗色截图在本机真实引擎测试中识别出了对阵、选择、赔率、本金、返还和投注时间；原图及输出未进入公开仓库。此结果不代表所有版式或手机端都通过。

当前限制：一次处理一张完整订单；同图多个独立订单提示裁剪。多图队列、最近导入任务列表、按图片哈希去重尚未实现；目前重复检查基于事件、平台、本金及邻近时间。不同平台、复杂照片、裁剪或 OCR 错字需人工修正。游戏图标不自动映射类别，未知平台不套用其他截图。仅支持 CNY 整数分，超过两位且非尾零的金额不静默舍入。

手机验收：识别入口导入 → 检查日期/金额 → 检查分项 → 勾选最终确认 → 保存后再编辑 → 导出备份。照片选择器可能触发自动锁定，仍需实机验证；不清除网站数据进行更新。
