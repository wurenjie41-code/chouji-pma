# 筹记（WagerMemo）PWA V1

运行于 iPhone Safari/主屏幕的本机资金记录工具。纯 HTML、CSS、JavaScript，无框架、后端或外部数据源；Windows 可开发和发布，不需要本机 Mac/Xcode。旧 Swift 工程及其他资料仍保留在仓库其他目录。

## 本机预览

需要 Node.js 18 或更高版本，无需安装 npm 依赖：

```powershell
node .\pwa-v1\serve.mjs
```

电脑访问 `http://127.0.0.1:4173`。本机 localhost 可用于加密 API 预览；不要通过局域网 HTTP 在手机上存入真实账本。

## iPhone 15 安装

1. 确认 GitHub 仓库 **Settings → Pages → Source** 为 **GitHub Actions**。
2. 推送 `main` 后等待 **Actions → Publish Chouji PWA to GitHub Pages** 成功。
3. 在 iPhone 15 的 Safari 打开 `https://wurenjie41-code.github.io/chouji-pma/`。
4. 点“分享”→“添加到主屏幕”。首次用临时数据检查页面与解锁后，再录入个人数据。

GitHub Pages 是公开静态托管。公开的是程序和图标，不是存放于设备浏览器的账本；不要把真实流水、备份文件或口令提交到 GitHub。

## 当前功能

- **概览**：本周期预算使用与剩余、已结算投注净结果及 ROI、未结算投注额和笔数、净存款及记录推算资金变化。投注结果与账户存取分开显示；旧版未关联流水单独保留。
- **逐注记录**：手工记录比赛、类别、联赛、玩法、平台、赔率、金额、单关/串关、结算状态、实际返还、手续费、赛果、标签、备注和下注前状态；支持搜索、状态筛选、编辑、删除和本机修改历史。
- **历史分析**：按法定月、自然周、自定义范围或全部记录查看；可按投注日期或结算日期筛选，并按类别、联赛、玩法、赔率区间、平台、时段或星期分组后钻取明细。显示字段完整度、样本量、平均/最大单笔、赢输笔数和最长连赢/连输；结果只描述历史，已结算样本少于 30 笔时提示数据不足。
- **预算与风险保护**：可预设周期预算、亏损上限、最大单笔和允许记账时段；接近/达到上限、短时密集投注、深夜集中记录、亏损后加大单笔或短期存款时显示可解释提醒。可停止当前周期新增记录或开启冷静期。锁定只约束本工具，不能阻止外部平台下注。
- **旧账兼容**：旧版流水原样保留，不推断其赛果或结算状态；升级时在内存补齐状态字段，保存时再写入新版状态。新独立退款不与旧版投注盈亏重复计算。
- **加密与恢复**：账本以 AES-256-GCM 加密，PBKDF2-SHA256（600,000 轮）派生口令密钥；每次成功保存后生成最多 5 份本机加密快照，可恢复上一版。加密 JSON 备份经密码验证后只导入空账本，不覆盖现有账本。
- **明文 CSV**：导出前明确提示个人信息和未加密风险；文本字段做电子表格公式注入防护并使用 UTF-8 BOM。导出文件不受账本加密保护，需自行安全保存。
- **离线与存储提示**：Service Worker 缓存应用资源但不缓存账本；申请浏览器持久存储、显示配额并在接近上限时提醒。

所有金额以整数分保存，单一 CNY 账本。已结算投注净结果 = 实际返还（含本金）− 投注额 − 手续费；ROI = 已结算投注净结果 ÷ 已结算投注额，作废投注不进入 ROI。净存款 = 存款 − 提款，投注净结果与存取款造成的资金变化分别展示。此工具只记录用户手动输入的信息，不提供预测或投注建议。

## 数据与安全边界

应用没有服务器和云同步。IndexedDB 主账本与滚动快照留在当前浏览器来源；加密导出文件可以手动放到独立安全位置。导出文件虽然不含明文流水，任何人拿到它仍可尝试猜测账本密码，因此应当安全保存并使用强口令。忘记口令无法找回；浏览器清理、设备故障或文件丢失仍可能导致数据无法恢复。

这是 PWA，不是原生 iOS App；不使用 SQLCipher、iOS Keychain 或原生 Face ID，也没有 App Store 安装包。移动 Safari 的文件保存/选择体验、离线启动、预算交互和存储持久性需要在目标 iPhone/iOS 版本上实机确认。暂不支持多币种、多账本、云同步、OCR、图片附件、赛事/赔率 API 或 CSV 导入；来源目前标记为手动录入。

## 目录

- `DATA_MODEL.md`：IndexedDB、加密 envelope、资金流水与备份格式
- `IMPLEMENTATION_PLAN.md`：已完成项、发布与设备检查计划
- `RISK_MANAGEMENT_ROADMAP.md`：从当前流水版迁移到个人投注记录与风险保护的分阶段方案
- `index.html`：页面与安装元数据
- `src/app.js`：页面渲染、分析与交互
- `src/storage.js`：IndexedDB、WebCrypto、快照、加密备份
- `src/styles.css`：响应式界面
- `sw.js`：离线静态文件缓存
- `serve.mjs`：Windows 本机预览服务器
