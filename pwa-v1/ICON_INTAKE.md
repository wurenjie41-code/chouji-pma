# 图标类别与两步入账 S2（2026-11-17）

正常路径：选择图片或拍照 → 自动准备模型、预处理、OCR、解析和图标候选匹配 → 用户核对后点击“确认并保存”。额外确认勾选已并入保存按钮；缺失或错误字段仍需在同一确认页修正，不能为了两步而猜测数据。疑似重复、超限等异常仍可能出现提示。

图标候选：针对已提供版式，识别左侧订单项目图标的颜色、位置、尺寸/比例，生成 Dota 2 或 CS 候选，不通过队名推断。不是通用视觉模型，不保证其他平台图标准确，也不区分 CS 版本。图标不匹配时不填写类别。混合项目串关整单显示混合项目，仅在图标数与分项数相等时按顺序填入各分项类别；用户仍须核对。

真实截图本机测试：一张 Dota 图标、一张 CS 图标、一张含四分项的混合串关分别得到 Dota 2、CS、Dota 2/Dota 2/CS/CS 候选。测试预处理像素留在忽略目录，不提交公开仓库。这是有限版式测试，不是广泛准确率声明。
