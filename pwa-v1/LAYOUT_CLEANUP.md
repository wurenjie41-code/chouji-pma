# 样板布局整理 S1（2026-11-17）

导航统一为识别、账本、分析、我的。识别首页只保留图片/拍照入口、最近入账；旧资金总览从可见首页移除。备份/恢复/CSV 和预算入口归入“我的”。识别核对改为全屏，常用分类默认收起；选图后自动识别，成功后收起原文，保留字段供核对修改。原文可再次展开检查。

旧 HTML 已归档至 docs/ui-archive，不发布到 Pages。当前旧汇总渲染仍有兼容依赖，对应节点在运行页面中保持 hidden，避免这次界面整理引发统计代码异常；不作为可见旧版本入口。后续可拆除兼容渲染，当前不宣称所有旧代码已删除。

数据库来源、名称、密钥、IndexedDB 版本不变。仅递增静态程序缓存。移除图片时同步取消识别，防止已移除照片的迟到结果带入表单。

本机测试：另外三张用户截图在本机 OCR 后核对，本金、实际返还及单注赔率均与人工读图一致；其中串关检出四分项和相应赔率。照片、预处理图片及识别原文仅在被忽略的本机测试目录，未上传仓库。此测试用桌面引擎与反色预处理，不等同 iPhone 浏览器完整交互验收，也不代表任意照片均准确。

尚未交付：多图队列、最近导入任务状态列表、全部分析样板的逐像素还原。当前优先整理识别与核对流程，保留现有账本与分析能力。
