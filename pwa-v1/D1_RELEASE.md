# 筹记九屏重构版 D1 验收记录

日期：2026-11-17。此文件取代早期版本的当前状态说明；旧开发资料保留供追溯。

## 已实现

- 图片导入、识别确认、统计分析、流水、订单详情、分类分析、资金流水、预算保护、我的设置九个主要页面，另有金额分布页。原页面已归档，运行页面只引用新的 design.css。
- 相册多选（每批最多十张、每张不超过 10MB）和拍照入口，逐张识别、逐张确认。识别成功自动填充，不再额外勾选字段；缺失或歧义字段需核对补全。确认保存前不入账。
- 中英文 OCR 引擎与模型同源发布；暗底转亮底、图像缩放、Dota/CS 图标候选及篮球/足球文字类别。没有实样的篮球/足球图标不冒充已验证识别。
- 单注和串关分项、选择、局数、赔率、投注时间（保留秒）、开赛文字、金额、返还、来源、未知结算日期。订单号忽略。DB 风格长截图仅抽取首个完整订单，汇总与下一个截断订单不混入；不把“最高可赢”当实际返还。
- 图片哈希防重复，原图片不进入加密账本。不同裁剪或重拍仍可能绕过哈希；原有字段重复提示保留。
- 最近七天、本月、自定义范围与投注/结算日期口径；分类、平台、玩法、时段、赔率区间、样本量、笔数、投注额、净结果、ROI、平均赔率、最大单笔、胜率和累计净结果零线图。整单与串关分项分开。
- 手续费可见输入已去除，新增记录费用为零；历史费用保留，避免篡改旧账结果。
- 原加密账本命名空间和备份格式保留，新增字段兼容校验；日期统计默认口径加密保存。预算、冷静期、纠错和备份继续可用。

## 已完成的验证

- acceptance、recognition-test、receipt-test、design-test 四组自动检查通过，涵盖金额、ROI、资金变化、日期范围、字段解析、DB 首卡隔离、串关、备份字段兼容、非法数据拒绝和离线资源引用。
- 实际桌面浏览器 393×852 视口检查九个页面、筛选和详情，并使用合成图片运行本机 OCR，验证自动填充和相同图片防重复。浏览器脚本错误日志为空。
- 浏览器界面验收使用虚构数据及隔离保存替身；它验证交互，不代表在真实 iPhone 上完成加密保存往返。真实设备验收仍待用户完成。
- 实际实现截图位于 ../docs/visual-qa/。截图均为虚构数据，部分截图之后另修正了秒数保留、流水日期标题及备份入口顺序。

## 仍有边界

- 九屏内容和布局已重构；无法声称与生成的样板图片逐像素一致，也尚未通过 iPhone 实机视觉验收。
- DB 原始图片当前路径不可读，本轮只有相应版式解析回归检查，不能声称原图在手机已复测通过。
- 模糊、反光、遮挡、特殊图标和新平台版式可能缺字段；识别是候选数据，必须经用户确认。缺失时允许补全，不能保证任何图片都两步零修改。
- 币种目前固定 CNY 整数分。加密备份只导入空账本；非空账本入口明确说明限制，不覆盖旧数据。支持恢复本机快照。
- 语音仅在浏览器确有设备端中文识别能力时启用；否则可用系统键盘听写。尚无音频文件转写。
- 本机 OCR 首次需联网加载模型。iPhone 主屏幕下的相册返回、后台锁定、离线冷启动、模型加载耗时与备份往返仍待实机检查。
- 风险保护只限制本工具的新增记录，无法拦截外部平台投注；统计描述历史，不预测盈利。
